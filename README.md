# RitmUp

RitmUp — простой дневник питания и активности с игровыми сериями в духе Duolingo. Приложение помогает отмечать съеденные и потраченные калории, утренний вес и ежедневный прогресс, а также делиться достижениями с друзьями.

Сайт: [ritmup.ru](https://ritmup.ru) — станет доступен после завершения делегирования домена.

## Возможности

- регистрация и вход по email и паролю;
- отдельные аккаунты и уникальные имена пользователей;
- дневник съеденных и потраченных калорий;
- запись утреннего веса;
- ежедневная серия и история прогресса;
- поиск пользователей и заявки в друзья;
- лента достижений друзей;
- настройки приватности без публикации точного веса и калорий;
- адаптивный интерфейс для iPhone и установка как веб-приложения;
- автоматический HTTPS и обновление сертификата.

## Структура репозитория

- `selfhost/` — основное приложение с аккаунтами, PostgreSQL и Docker Compose;
- `ios/` — нативная оболочка iPhone и мост к Apple Health;
- `app/` — первоначальный интерфейсный прототип;
- `public/` — общие статические материалы.

Подробная документация серверной версии находится в [`selfhost/README.md`](selfhost/README.md).

## Локальный запуск основной версии

Понадобятся Node.js 20+ и PostgreSQL.

```bash
cd selfhost
cp .env.example .env
npm install
npm run db:migrate
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:3000`.

## Развёртывание через Docker

```bash
cd selfhost
cp .env.example .env
# Заполнить домен, пароль PostgreSQL и секрет авторизации в .env
docker compose up -d --build
```

Caddy автоматически получает TLS-сертификат, когда DNS-записи домена начинают указывать на сервер.

## Обновление работающего сервера

Проект установлен в `/opt/ritmup`. Для публикации новой версии:

```bash
ssh deploy@194.113.38.147
cd /opt/ritmup
git pull --ff-only
cd selfhost
docker compose up -d --build
```

Проверка состояния:

```bash
docker compose ps
docker compose logs --tail=100 app caddy
```

Секреты хранятся только в серверном файле `selfhost/.env` и не должны попадать в Git.
