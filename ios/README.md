# RitmUp для iPhone

Нативная оболочка открывает `https://ritmup.ru` в `WKWebView` и добавляет мост к
HealthKit. Пользователь входит в обычный аккаунт RitmUp, нажимает на экране
«Сегодня» кнопку синхронизации и сам подтверждает системный запрос Apple.

Приложение читает только:

- активную энергию за текущий день;
- шаги за текущий день;
- минуты упражнений за текущий день;
- последний записанный вес.

Доступ только на чтение. Пульс, медицинские записи и тренировки не запрашиваются.

## Сборка

Нужен Mac с актуальным Xcode. Проект описан через XcodeGen:

```bash
brew install xcodegen
cd ios
xcodegen generate
open RitmUp.xcodeproj
```

В Xcode открыть target `RitmUp` → `Signing & Capabilities`, выбрать свой Team и
проверить, что capability HealthKit включена. Затем подключить iPhone кабелем,
выбрать его как устройство запуска и нажать Run.

С бесплатным Apple Account приложение можно проверять на собственном iPhone, но
профиль придётся периодически обновлять. Для передачи Лизе через TestFlight нужна
подписка Apple Developer Program.

## Как работает синхронизация

Swift-код отправляет странице событие `ritm-health-data`. Страница сохраняет
полученную сводку через авторизованный `POST /api/health-sync`; cookie остаётся в
хранилище `WKWebView`, поэтому отдельный пароль или Health-токен внутри приложения
не нужен.

Версия через «Быстрые команды» остаётся рабочим бесплатным вариантом без сборки
нативного приложения.
